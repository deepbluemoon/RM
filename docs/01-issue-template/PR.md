# docs: 계약위험탐지 프로젝트 이슈 템플릿과 작업 기준 정비

## 문제와 변경

기존 양식은 SSH·백업·컨테이너 전환에 치우쳐 최소 구동 조사와 구현의 범위가 혼동될 수 있었다. 기능 개발을 위한 인수 조건 양식도 없었다.

기능 개발·오류 수정·최소 구동 점검의 세 양식으로 정리하고 작업 유형·구동 범위·검증 상태·완료 판정 기준을 명시했다. 탐지·근거·설명 변경에는 평가 사례와 비교 기준을 기록하도록 했다.

루트 AGENTS.md에서 이 작업 기준을 연결해 이후 AI 작업에도 적용한다.

## 주요 파일

- AGENTS.md: 이후 AI 작업의 범위·검증·push 지침.
- .github/ISSUE_TEMPLATE/: 실제 적용 템플릿 3개.
- docs/01-issue-template/: 사용 안내·조사 이슈 예시·검증 기록 및 동기화한 사본.

## 검증

현재 변경의 검사 결과와 미실행 범위는 docs/01-issue-template/VERIFY.md에 기록한다. 문서·템플릿 변경이며 앱 실행이나 탐지 정확도 검증을 수행한 것으로 해석하지 않는다.

이 문서는 PR 본문 예시다. 실제 이슈·PR 생성, 커밋, push는 수행하지 않았다.
